## 3. 발견한 문제 (근거 있는 것만)

### 3-1. 보유상한 1일이 수익을 잘라먹는다 ← 가장 큰 문제

대시보드 자체 통계: D+1 평균 승률 71% → **D+2 +3.04% / 승률 73% (n=11)** → D+3 67%.
청산 12건 중 D+2 데이터가 있는 9건으로 반사실 계산:

| | 실제 (배리어 청산) | D+2 종가 단순 보유 |
|---|---|---|
| 합계 수익률 | **-4.08%** | **+27.0%** |
| 승 / 패 | 3 / 6 | 6 / 3 |

개별 사례:
- SWKS 09-10: SL -4.56% → D+2 +6.8%, MFE20 +8.5%
- SWKS 09-11: SL -2.83% → D+3 +6.1%
- META 09-09: TO -0.87% → D+5 +4.4%
- KHC 09-11: SL -1.93% → D+1~3 내내 +1.3%
- 미체결 DELL / HPE: D+3 각각 +9.3% / +9.8% (놓친 두 건이 가장 큰 수익)

→ "스윙 / 중단기 / 단타" 라벨을 붙여놓고 **실제 청산은 셋 다 1일 룰**로 돌아가고 있다. 라벨이 청산에 반영되지 않는 게 설계 모순.

### 3-2. 손절폭이 변동성 대비 너무 좁고, 슬리피지가 손실 쪽에만 붙는다

- TP는 +3% 부근에서 정확히 체결(VLO +3.00, SWKS +3.67)되는데 SL은 -2.8 ~ **-4.56%**로 목표보다 훨씬 나쁘게 체결됨 → 갭/장중 급락 슬리피지가 손실에만 반영.
- SL 트레이드의 MAE20이 -5.5 ~ -7.7%인 반면 MFE20은 +2.3 ~ +8.5%. 반도체(SWKS, HPQ)처럼 일변동 5% 넘는 종목에 고정 -3% 손절을 걸면 노이즈에 털린다.
- 결과적으로 TP:SL 실효 비율이 1 : 1.3으로 **역손익비**. 승률 42%면 최소 1.5 : 1은 돼야 본전.

### 3-3. 확신도(confidence)가 변별력이 없다

- 범위가 0.45 ~ 0.58로 사실상 한 구간. TP 평균 0.526 / SL 평균 0.502 → 차이 없음.
- 다만 **0.50 미만 4건(KR, KHC, SWKS×2)이 전부 손실**, 0.50 이상 8건은 5승 3패 · 합계 +4.56% · PF 1.51.
- n이 작아 확정은 못 하지만 "0.50 미만은 실행 안 함"은 지금 당장 적용해도 잃을 게 없는 필터.

### 3-4. 같은 종목 반복 추천 · 섹터 쏠림

- SWKS가 4거래일 연속 추천(09-10, 11, 14, 15). 2승 2패지만 손실 두 건이 다 초반 SL → 손절 직후 재진입 쿨다운이 없다.
- 09-17 대기 6건 중 4건이 반도체(AMD, SMCI, ARM, INTC). 종목당 $1,000 균등이라도 섹터 베타는 사실상 한 포지션.

### 3-5. 미체결 2건 원인 불명

DELL, HPE 둘 다 "미체결"인데 대시보드엔 이유가 없다. 실행 ✅ 표시인데 미체결이면 진입 로직(시가 체결 조건? 사용자 미실행?)을 로그로 남겨야 한다. 이 두 건이 표본 중 최고 수익이라 원인 파악이 중요.

### 3-6. 표본이 너무 작다 (전제)

거래일 7일, 청산 12건. 위 분석은 전부 "방향 힌트"지 통계적 결론이 아니다. **파라미터를 이 12건에 맞춰 튜닝하면 과적합**이므로, 변경안은 반드시 과거 시그널 전체로 백테스트한 뒤 적용한다.

## 4. 앞으로의 방향 (우선순위 순)

### P0. 청산 룰 재설계 — 백테스트 먼저, 그다음 적용

1. **보유상한을 라벨별로 분리**: 단타 D+1 → D+2, 중단기 D+3, 스윙 D+5 (초기값. 백테스트로 확정).
2. **손절을 고정 % → ATR 기반**: 예) SL = 진입가 − 1.5 × ATR(14), TP = 진입가 + 2.5 × ATR(14). 목표는 실효 손익비 ≥ 1.5 : 1.
3. **손절 판정을 종가 기준(close-based)** 으로 옵션화해서 장중 위크 털림 vs 갭 리스크를 비교.
4. 부분익절 + 트레일링(예: +1 ATR 도달 시 손절을 본전으로) 옵션 추가.
5. 그리드: hold ∈ {1,2,3,5}, SL ∈ {1.0,1.5,2.0 ATR}, TP ∈ {2,2.5,3 ATR} × close-based on/off → walk-forward로 PF·기대값·MDD·MFE 포착률 비교. **n ≥ 100 시그널**이 확보된 구간에서만 결론.

### P1. 실행 필터

- 확신도 < 0.50 실행 제외 (당장 적용).
- 동일 종목 SL 후 재진입 쿨다운 3거래일.
- 동시 보유 중 같은 섹터(GICS 또는 섹터 ETF 매핑) 2종목 이하.

### P2. 슬리피지·체결 현실화

- 백테스트 SL 체결가 = min(손절가, 다음 봉 시가) 로 갭 반영. TP도 대칭으로.
- 실제 체결가를 `triage` 입력에 함께 기록 → 예상 vs 실제 슬리피지 통계.
- 미체결 사유 코드 필드 추가 (갭업 초과 / 사용자 미실행 / 유동성 등).

### P3. 확신도 재보정

- 확신도 구간별(0.45/0.50/0.55/0.60+) 승률·기대값 테이블을 대시보드에 추가.
- 표본 쌓이면 Brier score / 캘리브레이션 곡선으로 점수 스케일 재조정. 지금처럼 0.45~0.58에 몰려 있으면 점수가 의미가 없다.

### P4. 대시보드 지표 보강

- 건당 기대값, 평균 익절/평균 손실, 실효 손익비
- 라벨별(단타/중단기/스윙) · 확신도 구간별 · 섹터별 분해
- MFE 포착률 = 실현수익 / MFE20 (지금 청산 룰이 얼마나 못 먹는지 한눈에)
- 반사실 컬럼: "D+2 단순보유 시 손익" 누적 곡선을 실제 곡선과 겹쳐 그리기

### 하지 말 것

- 12건 보고 스코어링 모델(종목 선정 로직) 손대기 — 선정은 지금 잘 되고 있는 편이다.
- 실거래 금액 늘리기 — PF ≥ 1.3, n ≥ 50 확인 전까지 가상/최소 단위 유지.
